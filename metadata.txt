about=Tresbolillo Grid Generator creates a staggered point grid inside polygon layers. It is designed for sampling, agricultural planning, field layouts, and GIS workflows that require a point pattern with alternating offsets. The input layer must use a projected coordinate reference system in meters, such as UTM. The plugin lets users choose the polygon layer, point spacing, output shapefile, and offset direction. No external dependencies are required.
