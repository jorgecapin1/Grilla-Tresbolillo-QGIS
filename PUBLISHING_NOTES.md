# Publishing checklist

Before uploading to the official QGIS plugin repository:

1. Create a public GitHub repository named `TresbolilloGridGenerator`.
2. Upload the same source files contained in this ZIP.
3. Replace these three metadata URLs:
   - homepage
   - repository
   - tracker
4. Confirm that the repository is public and not empty.
5. Test the ZIP installation in QGIS.
6. Upload the ZIP to plugins.qgis.org.
